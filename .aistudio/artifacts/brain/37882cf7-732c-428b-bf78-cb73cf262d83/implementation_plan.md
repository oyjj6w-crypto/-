# 铁板神数 (Tieban Shenshu) 安卓应用实现方案

将 GitHub 开源项目 `xaminxan/tiebanshenshu` 完整重塑并移植为现代原生 Android (Jetpack Compose) 术数排盘与百岁运程推演应用，完美再现宋代邵雍传世之“铁板神数”算法精粹与原/修正双栏断语对照。

---

## 确认决策与用户偏好 (User Review & Critical Decisions)

> [!IMPORTANT]
> 根据前置交互问答，本方案已固化以下核心设计决策：

- **视觉风格**：**典雅古籍国风**。采用宣纸暖白色调（#F9F6EE）、水墨玄青文字与边框（#1A1817）、朱砂印章红（#BA382A）与金石铜色（#C5A059）点缀，融合经折装古籍卡片与水墨纹理。
- **断语呈现**：**双栏对比视图**。1至100岁流年条文采用并列/对照卡片，左栏呈现古籍“原条文与原断语”，右栏呈现当代“校正条文与校正断语”，并标注推算公式、四声字母与干支标记。
- **时间与排盘**：**公农历双向转换与八字四柱即时换算**。内置精确的天干地支万年历换算逻辑，支持性别（乾造/坤造）、考刻（八刻细化与初正刻校准）、求测时间设置。

## 1. 概述与核心定位 (Overview & Core Concept)

### 产品定位
**铁板神数 (Tieban Shenshu)** 是一款专为国学传统数术爱好者、命理研究者打造的高精度排盘与断语推演安卓应用。

### 核心价值
- **算法纯正**：完整移植并优化 `xaminxan/tiebanshenshu` 算法：计算先天命数、五音命数、日命数、时运数、本命数、考刻结果及十二辟卦。
- **原版与修正对照**：彻底解决传统铁板数条文晦涩或版本错讹痛点，直观对照原断语和修正断语。
- **离线安全高可用**：所有排盘运算与条文数据均在本地高效运行，无需网络依赖，保障生辰隐私安全。

### 3.2 铁板数理公式算法实现
1. **四柱与考刻换算**：
   - 依据农历/公历与精确节气推算年、月、日、时四柱干支。
   - 考刻细分：子初一刻至亥正四刻，支持15分钟一刻精度。
2. **数理计算**：
   - 天干地支太玄配数与八卦纳甲。
   - 先天命数：年干数 + 月干数 + 日干数 + 时干数依据铁板定轨法则演化。
   - 五音命数：以姓氏五音配合四声清浊。
   - 日命数与时运数：日干支配合卦理起数。
   - 十二辟卦：按出生月份与节气对应复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤十二辟卦。
3. **百岁流年条文生成**：
   - 年龄 $1 \le age \le 100$：
   - 推算各年龄当年的行运干支与纳音。
   - 结合四声标记、定轨系数计算得出条文数编码。
   - 并行输出传统《铁板神数》原条文诗句以及现代《校正断语白话解》。

## 4. 实施阶段计划 (Implementation Steps)

1. **依赖与工程基建**：
   - 配置应用元数据（`metadata.json` 与 `strings.xml` 命名为“铁板神数”）。
   - 引入 Room 数据库用于本地排盘档案保存。
2. **数理与排盘核心算法引擎 (`engine/`)**：
   - `LunarCalendarUtil`：公农历精确换算、节气与天干地支四柱推算。
   - `TiebanShenshuCalculator`：移植原 GitHub 仓库的先天命数、五音命数、时运数、十二辟卦和流年公式推演。
   - `TiebanVersesRepository`：构建原断语与修正断语对照数据库与条文检索器。
3. **古籍国风 UI 组件与页面 (`ui/`)**：
   - `TiebanTheme`：宣纸暖白、水墨玄青、朱砂印章红等全套国风 Design Tokens。
   - `InputForm`：公历农历无缝切换、生辰八字即时换算、刻分微调器。
   - `FateMetricCards`：展示先天数、辟卦图、干支四柱的精美印章卡片。
   - `VersesComparisonList`：1-100岁双栏卡片，左侧原断语古韵，右侧修正断语今解，支持按年龄段快速跳转。
   - `HistoryDialog`：历史排盘查看与导出。
4. **验证与编译**：
   - 使用 `compile_applet` 确保构建无错，验证交互与排盘结果的准确性。
